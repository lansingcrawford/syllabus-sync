TARGET: Build Syllabus Sync, a one-page website for college students to upload one or more syllabus files.

TARGET: Let students choose which event types to extract: exams/midterms, finals, major projects, and presentations.

TARGET: Extract each chosen event with its course, title, date, category, and source syllabus when available.

TARGET: Present extracted events in a clear review list where students can select, edit, or delete them.

TARGET: Generate a downloadable calendar file only from events the student has explicitly confirmed.

TARGET: Keep the experience clean, responsive, understandable for first-time users, and robust for empty, unsupported, or unclear uploads.
